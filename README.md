# ecommerce-sales performence Dashboard (Excel)
## Project Overview 
An Interactive and dynamic ** Sales Analytics Dashboard** Developed in **Microsoft Excel**. The Dashboard Provides a high level view of key business performence metrices (KPIs), tracks product-level trends, and enables stakeholders to filter data effortlessly across dimensions. 

## Key Features & Highlights 
**KPI Metrices:** Total Revenue, Total Orders, Average Order Value (AOV), and Quantity Sold.
**Pivot Tables & Calculations:** Summerized transactional data by category, region, and timeline.
**Dynamic Slicers:** Interactive timeline and category/region slicers for real-time dashboard filtering.
**Formulas & Functions:** Utilized logical and lookup functions ('XLOOKUP','INDEX/MATCH','SUMIFS','COUNTIFS','ROUND').
**Data Visualizations:** Combinations of bar coulumn Charts, Trend line, and Pie/Donut breakdown charts for intuitive storytelling.

## Tools and skills applied 
**Applications:** Microsoft Excel
**Data Techniques:** Data Cleaning, Data Modelling, pivot Tables, Pivot charts, slicers, Dashboard design.
